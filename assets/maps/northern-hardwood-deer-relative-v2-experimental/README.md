# NHPA deer relative encounter v2 — public diagnostic package

`index.html` is a byte-identical copy of the NHPA-W002-T04 staged interactive map. It is self-contained and needs no live API, tiles, or external data service. The model remains `NOT_PROMOTED_FAIL_CLOSED` after public hosting. It is an experimental camera-encounter diagnostic, not deer density or browse pressure.

See `/northern-hardwood-deer-relative-v2-experimental-methods/` for inputs, validation results, citations, limits, and interpretation. Do not add raw camera coordinates, site identifiers, or interview data to this package.
