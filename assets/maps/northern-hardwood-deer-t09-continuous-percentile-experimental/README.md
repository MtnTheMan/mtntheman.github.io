# NHPA T09 continuous deer-encounter percentile — public research archive

`index.html` is a self-contained archival copy of the NHPA-W002-T09 local interactive viewer. Its map data and behavior are unchanged. The public copy changes only local-only publication wording, its browser title, and the methods link. The original research viewer remains unchanged in the canonical NHPA workspace.

This map is **experimental and not promoted**. It interpolates T04 modeled camera-encounter percentiles into 18,291 cells that T04 classified as high extrapolation. T04 failed independent geographic camera validation. Neither T04 nor T09 estimates deer/km², browse damage, or management quality. The support layer and [public methods page](/northern-hardwood-deer-t09-continuous-percentile-experimental-methods/) must remain available with the map.

The viewer embeds modeled 5-km cell values and simplified jurisdiction outlines only. It does not include raw camera locations, deployment identifiers, interview data, or a live data service. See `public_package_manifest.csv` for the original and public-copy SHA-256 hashes.
